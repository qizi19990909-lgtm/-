## 1. 总体风格

### 1.1 一句话
卡通 Q 版、1 头身：大头小身、粗深色描边、平涂色 + 一层硬阴影；可爱但带点「凶」和「贱」，方便做恶搞（学艺不精、部位放大）。【已定】

### 1.2 比例【建议】
- 「1 头身」落地定义：**身体（含腿）高度 ≈ 1 个头高**，头部约占全身高的 50%（±5%）。以 `角色设定_v1.jpg` 为基准。
- 头：宽略大于身体宽（约 1.1~1.2 倍），无明显脖子。
- 手：圆团手，不画手指细节（握武器时最多 3 根手指的剪影）；手臂短，自然下垂时手到腰下。
- 脚：两个小椭圆 / 小鞋，腿长 ≈ 身体高的 30%。
- 眼睛：占脸宽约 35%，位置在头部中线偏下；表情靠眉毛 + 眼睛 + 嘴三件替换。
- 怪物和 Boss 可以打破比例（Boss 可到 1.5~2 头身显得压迫），但描边、上色规则不变。

### 1.3 像素尺寸【建议，开发确认】
以横屏 1280×720 为设计基准（逻辑分辨率），资源按 2 倍制作（2560×1440 下清晰），Godot 用 `canvas_items` 拉伸。

| 对象 | 屏幕上高度（1280×720 下） | 2 倍源文件高度 | 占屏高 |
|---|---|---|---|
| 玩家角色 | 约 110 px（头约 55 px） | 约 220 px | ≈15% |
| 小怪 | 80~110 px | 160~220 px | 11~15% |
| 精英 | 140~165 px（1.3~1.5 倍） | 280~330 px | ≈20% |
| Boss | 220~330 px（2~3 倍） | 440~660 px | 30~45% |
| 武器（手持） | 长 50~80 px | 100~160 px | — |
| 投射物 | 20~40 px | 40~80 px | — |

理由：同屏最多 5 名角色 + 15~30 只怪，110 px 能保证脸和职业标志物在 6 寸手机上看清，又给走位留出空间。

### 1.4 描边【建议】
- 颜色：深棕 `#3B2A20`（不用纯黑，画面更暖、更柔和）。
- 粗细（以 1280×720 显示为准）：角色 / 怪物外轮廓 3 px，内部结构线 1.5~2 px；Boss 外轮廓 4 px；场景物件 2 px，且描边颜色提亮到 `#5A4636`，让场景退后。
- 2 倍源文件里线宽相应 ×2（外轮廓 6 px）。
- 特效、光效、伤害数字之外的所有元素都要描边；特效不描边（用亮色边缘），以此和实体区分。

### 1.5 光影【建议】
- 平涂 + **一层硬阴影**（阴影色 = 底色明度 -20%、略偏冷/偏紫），光源统一在左上方。
- 可选一道高光（只用于金属、宝石、头发），不做渐变、不做软阴影。
- 角色脚下统一一个半透明深色椭圆阴影（不随光源变化），方便判断站位。

### 1.6 配色规则
**整体**：角色饱和度最高，怪物次之，地面最低（比角色低约 20~30% 饱和度），保证「人一眼能从地上跳出来」。

**区域主色板【建议】**（每区 4 主色 + 1 点缀色，HEX 仅作基准）：

### 1.7 可读性规则【建议】（全项目强制）
1. **剪影优先**：每个职业、每种怪，涂成纯黑后在 64 px 高度下仍能认出来（见 2.3）。
2. **敌我区分**：我方脚下有淡蓝色细圈；敌方没有，被选中时显示红圈；Boss 脚下常驻暗红圈。
3. **治疗 / 增益 = 绿或金，飞向队友；伤害 = 属性色，飞向敌人**（玩法文档 3.7 已定方向）。
4. **危险预警**：Boss 和精英的大招先在地面画红色半透明警示区（0.8~1.5 秒），再出伤害。
5. **特效让位**：我方特效同屏过多时自动降到 70% 不透明度；设置里提供「简化特效 / 只显示我选中角色的特效」。
6. **地面低对比**：可走区域内不放高对比图案、不放和角色同色的物件。
7. **状态图标**：统一挂在角色头顶；属性叠层用 1~5 个小圆点显示在血条下方，颜色 = 属性色。

## 2. 人物

### 2.1 一套共用 Spine 骨骼【建议，开发确认】
所有玩家角色共用同一套骨骼（同名骨骼、同名插槽），换角色 = 换皮肤；动画只做一份，所有角色通用。

**骨骼清单**
| 骨骼 | 父级 | 用途 |
|---|---|---|
| root | — | 位置、朝向（左右镜像）、整体缩放 |
| hip（身体中心） | root | 身体上下起伏 |
| body（身） | hip | 身体；**部位放大：身** |
| head（头） | body | 头；**部位放大：头** |
| hair_back / hair_front | head | 头发前后片，可做飘动 |
| headgear（头饰） | head | 职业标志物 / 头饰 |
| face_eye / face_brow / face_mouth | head | 表情（换图，不做骨骼变形） |
| hand_L（左手） / hand_R（右手） | body | 双手；**部位放大：左手 / 右手** |
| weapon_main | hand_R | 主手武器挂点 |
| weapon_off | hand_L | 副手挂点（弓的握把、双手武器的另一手） |
| foot_L（左脚） / foot_R（右脚） | hip | 双脚；**部位放大：左脚 / 右脚** |
| back（背饰） | body | 法宝 / 背饰 / 披风 |
| cape | back | 披风飘带（红 / 暗金档才用） |
| fx_head / fx_chest / fx_weapon_tip / fx_feet | 对应部位 | 特效挂点：状态图标、受击点、武器拖尾起点、脚底阵法 / 光环 |
| scale_* （6 个） | 对应部位 | 专门用来做部位放大的缩放骨骼，和动画骨骼分开，避免动画覆盖缩放值 |

**插槽清单**（从后到前的绘制顺序）
`fx_aura_back`（身后光环） → `back`（法宝 / 背饰） → `cape` → `hair_back` → `foot_L` → `hand_L` → `weapon_off` → `body`（衣服） → `body_detail`（腰带 / 坠饰） → `foot_R` → `head`（脸型 / 肤色） → `face_eye` → `face_brow` → `face_mouth` → `hair_front` → `headgear` → `weapon_main` → `hand_R` → `fx_front`（武器拖尾、前景光效）。
> 握武器时 `weapon_main` 在 `hand_R` 下面，让手「握住」武器；部分动作（背刺、投掷）可以用 draw order 关键帧临时调整。

### 2.2 部位放大 = 骨骼缩放，受击框不变【已定方向 21:23】
- 6 个部位（头、身、左手、右手、左脚、右脚）各自对应一个 `scale_*` 骨骼，每升一级放大一档。建议上限：头 1.5 倍；手和脚 1.8 倍；身 1.4 倍。超过上限的升级只改造型，不再放大，防止挡住队友和怪物。【建议】
- **受击框**：在 Godot 里用固定尺寸的胶囊碰撞体（宽约 50 px、高约 100 px，以 1280×720 为准），不读 Spine 的包围盒，所以放大不影响被打中的概率。【已定方向】
- 武器跟着手一起放大吗？【待确认】推荐**跟随放大，但武器最多 1.3 倍**，搞笑效果够用，也不会让大锤挡住半个屏幕。
- 攻击判定也不随放大改变（攻击范围只看武器和技能数据）。

### 2.3 6 个职业外观：识别要点和剪影【建议，以角色设定_v1.jpg 为基础】
原则：**头部和职业标志物属于职业，不被装备盖住**，身上的衣服和手里的武器则跟着装备变（见第 3 节）。

| 职业外观 | 对口武器 | 职业标志物（固定在头部） | 职业色 | 剪影特征 | 待机姿态 |
|---|---|---|---|---|---|
| 剑修 | 剑 | 头顶发髻 + 蓝色发带 | 白 + 蓝 | 头顶一个小圆点（发髻），剑竖直，整体修长 | 剑尖朝下斜握，站得笔直 |
| 战士 | 大刀 | 红色头巾，两条头巾尾飘在脑后 | 红 + 铁灰 | 头侧有飘带，大刀弧线向外，最宽的肩 | 大刀扛肩 |
| 体修 | 锤 | 光头 + 颈间大念珠 | 土黄 + 褐 | 圆头无发，身体最圆最胖，锤头方块 | 锤头拄地，双手压在柄上 |
| 阵法师 | 枪（当阵旗） | 高方帽 + 后垂飘带 | 青绿 + 金 | 最高的剪影：方帽 + 高出头顶的枪旗 | 枪旗立在身旁 |
| 弓手 | 弓 | 宽沿斗笠 | 草绿 + 褐 | 头顶宽三角（斗笠），全队头部最宽 | 弓斜背在身前，手搭弓臂 |
| 法师 | 法杖 | 高马尾长发 + 发饰 | 紫 + 金 | 长发下垂超过身体，杖头发光球 | 杖立身侧，杖头悬着光点 |

- 同一职业可以有多名可收集角色：共享职业标志物的「类型」（例如都戴斗笠），但脸型、发色、配饰、性别不同。【建议】
- 白档初始服的颜色使用该职业的职业色，所以玩家在没换装时也能靠颜色区分职业。
- 头顶「得心应手 / 学艺不精」标签：白底、深棕描边的小牌，挂在 `fx_head` 上方，只在进图前 3 秒和第一次触发不对口攻击时出现，不常驻，避免挡视线。【建议】

## 3. 换装即换外形（重点）【已定方向 pt17u：「更换装备外形也会更换」】

### 3.1 实现方式【建议，开发确认】
- 用 Spine 的**皮肤（Skin）+ 插槽附件（Attachment）**：每件装备 = 一组附件图片（按插槽命名）。穿上装备时，运行时把「角色皮肤 + 法衣皮肤 + 武器皮肤 + 法宝皮肤」**合并成一套组合皮肤**（Spine 4.x 支持运行时组合皮肤）。
- 数据上把**外观 ID 和数值分开**：装备表里有 `look_id` 字段，指向一组附件。这样以后做幻化、换色变体都不用改数值表。
- 命名规范：`{部位}_{区域档}_{造型}_{配色}`，例：`robe_t01_A_white`、`weapon_sword_t03_B_purple`、`artifact_t05_A_red`。
- 换装后立刻刷新显示，城镇、背包、战斗里都一致；背包里的角色预览用同一套 Spine，不另画立绘。

### 3.2 哪些装备有外观
玩法文档定的装备是 3 类：武器 / 法衣（护甲） / 法宝。【推荐】外观也按这 3 类，各管各的插槽：

| 装备 | 改变的插槽 | 说明 |
|---|---|---|
| 武器 | `weapon_main`（弓、双手武器另用 `weapon_off`）、`fx_weapon_tip` | 6 种武器，造型随档位和稀有度变 |
| 法衣 | `body`、`body_detail`、`hand_L/R`（袖口）、`foot_L/R`（鞋）、`cape`（红档起） | 衣服 + 袖子 + 鞋整套一起换，保证整体配色协调 |
| 法宝 | `back`、`fx_aura_back` | 背后悬浮的法宝（葫芦、铜镜、小鼎、符剑等），高档有光环 |

- 头部（脸、发型、职业标志物）**不随装备变**，归角色本身。这样每个职业剪影永远好认，角色收集也有意义。
- 头饰：红档、暗金档法衣可以附带一个**小冠 / 发饰**，叠加在职业标志物上，**不遮挡**职业标志物（例如斗笠上加一圈金边，而不是把斗笠换成头盔）。
- 【待确认】备选方案 B：把法衣拆成「头冠 / 衣服 / 鞋」3 个装备部位，共 5 个部位。好处是可搭配性更强；坏处是美术量约 ×1.6，玩法的装备数值也要重排，职业标志物可能被头盔盖住。**推荐保持 3 类。**

### 3.3 稀有度外观规则【建议】（见 `换装演进_剑修_v1.jpg`）
| 稀有度 | 造型 | 颜色 | 粒子 | 光效 / 拖尾 | 制作方法 |
|---|---|---|---|---|---|
| 白 | 本档基础造型 | 朴素本色（布、铁、木） | 无 | 无 | 基础造型 |
| 蓝 | 同白 | 换色（蓝色布条、蓝色缠柄） | 无 | 无 | **只换色**，零新图 |
| 紫 | **新造型**：加部件（护手、坠饰、领口、腰带） | 紫色主调 | 无 | 无 | 基础造型 + 部件 |
| 橙 | 第二套造型（更华丽的轮廓） | 橙金 | **有**：武器周围少量闪光粒子 | 无 | 新造型 |
| 红 | 第三套造型，加披风 | 绯红 + 金 | 有 | **有**：攻击时武器拖尾（绯红流光，不是火焰） | 新造型 + 拖尾 |
| 暗金 | 独特造型（每区域每武器 1 把「名器」） | 黑 + 暗金 | 有（金色） | **有**：常驻金色光晕 + 长拖尾 + 身后光环 | 手工精做 |

- 原则：**一眼能看出谁穿得好**——轮廓变复杂、颜色变贵、光效变多，三个维度同时往上走。
- 「玩法文档 3.7」的规则：橙色及以上才可能是套装；套装外观见 3.5。

### 3.4 属性武器加属性光效【建议】
- 武器带冰 / 火 / 电 / 暗属性时，在 `fx_weapon_tip` 上叠加属性光效：冰 = 寒雾 + 雪花粒子；火 = 刃口火舌；电 = 跳动电弧；暗 = 拖尾紫烟。
- **稀有度决定「强度」，属性决定「颜色和形状」**：例如紫档火属性 = 小火苗；暗金火属性 = 整把武器燃烧 + 金色光晕 + 火焰拖尾。同时存在时，拖尾颜色改用属性色，光晕保留稀有度色。
- 有属性时普攻命中特效也换成属性版（每种武器的命中特效 × 4 属性 = 用换色 + 叠加粒子实现，不另画动画）。

### 3.5 套装集齐有整体外观【建议】
- 套装件数：玩法文档定为 2 件 / 3 件触发（武器、法衣、法宝 3 件）。
- 2 件：两件装备的配色统一（法衣花纹和武器缠柄同色），脚下出现淡淡的套装纹样。
- 3 件（集齐）：切换成「**套装形态**」——法衣换成套装专属变体（多一件披风或飘带），身后出现套装专属光环，武器拖尾改成套装色。每套只额外画 1 套变体附件 + 1 个光环，成本可控。

### 3.6 成本控制：每档做几种造型【建议，开发确认】
12 档装备（每 5 级 1 档），6 个区域，每个区域 2 档。建议**同一区域的 2 档共用造型**，后一档只加细节和换色。

**每个区域、每种武器：**
| 造型 | 覆盖 | 数量 |
|---|---|---|
| 基础造型 A | 白、蓝（换色），紫（A + 部件） | 1 个 + 1 套部件 |
| 造型 B | 橙 | 1 |
| 造型 C | 红 | 1 |
| 名器 | 暗金（从天衡城起，青石村和落枫镇可以没有暗金） | 1 |
→ 约 4 个造型 × 6 区域 ≈ **每种武器 24 个造型**，6 种武器 ≈ 144 个武器造型；靠换色得到约 400 个可掉落外观。

**法衣**：同样约 4 套 × 6 区域 ≈ 24 套；**法宝**：约 3 种 × 6 区域 ≈ 18 个。套装另算，每套 1 套变体。

**扩量手段**：
1. 换色（调色板替换，Godot 着色器实现，零新图）。
2. 部件组合：护手 × 剑身 × 坠饰自由组合，3×3×3 = 27 种组合。
3. 区域材质：同一个造型轮廓，换材质贴图（木 → 铁 → 青铜 → 鎏金 → 兽骨 → 陨铁）。

**第一版（青石村 1~10 级）**：4 种武器 × 2 个造型（A、B）+ 法衣 2 套 + 法宝 2 个，加上换色，够覆盖白到橙。红和暗金等第二区域再做。

### 3.7 外观幻化（可选）【待确认】
- 做法：获得过的装备外观自动进「外观图鉴」，可以把喜欢的外观套到任何同部位装备上（数值不变）。
- 好处：收集价值高；以后若做商业化也是常见的外观付费点（**按老板要求现阶段不讨论充值**，只记一句）。
- 坏处：「看外观就知道谁强」的可读性会被破坏；排行榜截图也看不出真实装备。
- **推荐：第一版不做，但数据结构预留 `look_id`（3.1 已含），以后随时能加。** 如果做，建议给一个「显示真实外观」开关。

### 3.8 和角色外观养成的分工【建议，待确认】
角色升级、合成、进化只改外观（玩法文档 3.8 已定），但身体会被法衣盖住，所以要分清楚谁管哪里：
- **角色（养成）管**：头（脸、发型、职业标志物的豪华版）、部位放大、脚底光环、进化后的待机小动作。
- **装备管**：衣服、袖子、鞋、武器、背后法宝。
- 一句话：**头归角色，身归法衣，手里归武器，背后归法宝。**

## 6. 地图

### 6.1 视角：【建议】地面三分之四俯视（俯角约 30°）+ 角色侧视
- 地面、建筑按约 30° 俯视画（能看到地面纵深和屋顶），**角色和怪物用侧视**，只做左右两个朝向（另一边用镜像）。
- 理由：
  1. 同屏 5 人 + 一群怪需要上下纵深来走位、躲预警圈；纯横版侧视会让所有人挤在一条线上。
  2. 阵法是地面圆阵，需要俯视才能看清范围（画成椭圆）。
  3. 全等距（斜 45°、8 方向角色）需要每个动作画多个朝向，动画量 ×4 以上；角色侧视只需 1 套。
  4. 和风格基准图、老板参考图一致，同类 Q 版游戏的成熟做法。
- 深度：Godot 用 Y 排序（脚底越靠下越靠前）。

### 6.2 单屏战场构图（横屏 1280×720 基准）【建议】（见 `地图_青石村战场_v1.jpg`）

## 7. 动作规范

### 7.1 共用动作清单【建议】
所有玩家角色共用一份；人形怪复用其中一部分。时长为 1 倍攻速下的数值，Spine 按时间轴做（导出 30 帧/秒参考）。

| 动作 | 名称（Spine） | 时长 | 循环 | 要点 |
|---|---|---|---|---|
| 待机 | idle | 1.2 秒 | 是 | 身体上下起伏 2~3 px，偶尔眨眼 |
| 移动 | run | 0.5 秒 | 是 | 小碎步，头上下弹，身体前倾 |
| 普攻 | attack（按武器模板） | 0.5 秒 | 否 | 蓄力 0.15 / 出手 0.05（**hit 事件**）/ 收招 0.3 |
| 暴击 | crit | 0.7 秒 | 否 | 动作更夸张（跳起、转圈），出手瞬间停顿 2 帧（顿帧） |
| 背击 | backstab | 0.6 秒 | 否 | 闪身（一团烟 + 残影）到敌人背后再出手 |
| 施法 | cast | 0.8 秒 | 否 | 举起武器、脚下亮阵；阵法师插旗 |
| 受击 | hit | 0.25 秒 | 否 | 后仰 + 闭眼 + 闪白 1 帧 |
| 眩晕 / 麻痹 | stun | 0.8 秒 | 是 | 头顶转圈星星（麻痹加电弧） |
| 冰冻 | （不单独做） | — | — | 定格当前帧 + 半透明冰块覆盖 + 偏蓝着色 |
| 恐惧 | fear | 0.5 秒 | 是 | 双手抱头乱跑，冒冷汗 + 紫烟 |

### 7.2 6 武器 × 对口 / 不对口：动作复用方案【建议，开发确认】
36 种「职业 × 武器」组合，每种有普攻、暴击、背击 3 个动作。按玩法文档 3.8 的 4 条规则，**只需要 10 套攻击动作，而不是 36 套**：

| 动作套 | 覆盖组合 | 数量 | 说明 |
|---|---|---|---|
| 对口 6 套 | 剑修-剑、战士-大刀、体修-锤、阵法师-枪、弓手-弓、法师-法杖 | 6 组 | 正统动作，精做 |
| 规则 1：远程拿近战 → 把武器当投射物 | 弓手 / 法师 × 剑、大刀、锤、枪（8 组） | 2 套 | 弓手 = 「投掷」动作；法师 = 「念力悬浮发射」动作。投射物直接用武器附件图（旋转飞出） |
| 规则 2：近战拿远程 → 当钝器 | 剑修 / 战士 / 体修 × 弓、法杖（6 组） | 1 套 | 「抡棍」动作，武器挂在手上 |
| 规则 3：近战拿别的近战 → 错误握法 | 剑修 / 战士 / 体修 × 其他 3 种近战（9 组） | **0 套** | 直接用该职业的对口动作，只换附件，加一个「握错」的偏移 / 旋转配置（剑当锤砸、锤像剑一样戳） |
| 规则 4：阵法师拿非枪 → 武器从阵中落下 | 阵法师 × 其他 5 种（5 组） | 1 套 | 「插旗召唤」动作；落下物用武器附件图 |
| 合计 | 36 组 | **10 套 × 3 动作 = 30 个攻击动作** | 再加 7.1 的通用动作 |
- 命中特效按武器分 6 种（斩击弧、横扫弧、砸地裂、刺击点、箭矢、法球），属性版靠换色。
- 不对口伤害波动 ±30%（玩法文档）：波动的「高」端触发更夸张的命中特效（大一号的星星 + 屏幕轻震），让玩家感受到「乱拿武器有惊喜」。
- 手工彩蛋：后续挑几组人气组合单独做（例如法师拿锤 = 锤子悬浮在头顶转圈后砸下）。
- 示意：`学艺不精_弓手拿锤_v2.jpg`（规则 1：普攻把锤扔出去 / 暴击跳起砸地 / 背击闪到背后敲头）。

### 7.3 阵法与特效层级【建议】
- 阵法 = 地面层椭圆图案（俯视压扁约 0.5），跟随阵法师移动（玩法文档已定）；不同阵法用不同颜色 + 不同纹样（攻击阵红橙、增益阵金、减益阵紫、治疗阵绿）。

### 7.4 投射物【建议】
- 弓：箭有拖尾；法杖：法球有光晕；不对口投掷：直接用武器图片，飞行中旋转。

## 9. 版权合规与工作量风险

### 9.1 版权合规
1. 淘宝 Spine 素材（老板参考图）：**只作风格参考**。若要购买使用，必须拿到书面的商用授权，确认是否允许上架海外、是否允许修改；即便有授权，主角和可收集角色也要原创，不能用素材包里的角色。
2. 参考游戏（迷之国度、独奏骑士、提灯与地下城、热血江湖、斗战神、英雄联盟、DNF）：只借鉴玩法结构，名称、角色、图标、美术、数值全部原创（沿用玩法文档红线）。
3. AI 生成图：目前多地法律对纯 AI 生成内容的著作权保护不确定，正式资产必须经过人工重画 / 实质性修改，并保留制作过程文件；提示词里不写他人作品、品牌和画师名字。
4. 《山海经》属公有领域，可以取材，但造型要原创，避免和现有游戏里的同名异兽撞脸。
5. 字体、音效、Spine 运行库都要核对授权（Spine 编辑器需要购买授权，使用其运行库也受 Spine 授权条款约束）。【开发确认】

### 9.2 工作量与技术风险【开发确认】
1. **Godot + Spine**：官方 spine-godot 运行库需要使用对应版本的 Godot 定制编辑器或扩展，引擎升级会受版本锁定；需开发部先做技术验证（组合皮肤、骨骼缩放、换色着色器、同屏 30+ 骨骼动画的手机性能）。
2. **换装外观量**：完整 60 级约 144 个武器造型 + 24 套法衣 + 18 个法宝 + 套装变体，是最大的美术成本；第一版只做青石村（见 3.6）。
3. **动作量**：通用动作 13 个 + 攻击动作 30 个；第 3 条规则「错误握法」只靠配置，需要开发部确认附件偏移方案可行。
4. **特效量**：6 种命中特效 × 4 属性 + 稀有度光效 + 阵法图案；同屏特效多时手机发热和掉帧要尽早测。
5. **双屏幕方向**：UI 两套布局，战斗镜头规则两套，工作量明显增加（玩法文档已记）。
6. **可读性风险**：部位放大、多阵叠加、伤害数字、特效同屏时最容易糊，要在原型阶段就用最坏情况（5 人全暗金 + 4 层阵 + 30 只怪）测试。
7. **AI 图不能直接用**：AI 出的是整张图，Spine 需要分层、分部件的图，必须由美术重画拆件。

- 动作：全职业、男女、全部外观共用一套骨骼与动作。
  - 基础 9 个：待机、走路、受击、死亡、复活、胜利、眩晕、冰冻、恐惧。
  - 攻击按武器分不按职业分：剑、大刀、锤、枪、弓、法杖 × 普攻/暴击/背击 = 18 个。
  - 合计 27 个动作。职业差异只靠外观与特效颜色。
  - 「学艺不精」不另做动作：借用另一种武器的动作并替换投射物/武器图（如弓手拿锤＝拉弓动作射出锤子）。

### 12.3 动作归属【已定 11-19 18:55，取代 12.2 中"攻击按武器分"】
- 人物模型定稿：六职业男女白装_v8.jpg。
- 动作由职业决定，与武器无关：6 职业 × 普攻/暴击/背击 = 18 个攻击动作 + 9 个基础动作 = 27 个，男女与全部外观共用。
- 武器只决定：手持图 / 投射物图、命中特效（锤＝砸地震波、法杖＝法术光、剑＝剑光等）、词条与属性特效。
- 例：战士任何武器都是举起砸下（拿弓＝抓弓一头砸）；弓手任何武器都是射出（拿剑＝把剑射出去，命中为剑光）。
- 美术规范：所有武器统一握点；投射类职业（弓手、法师、阵法师）所用武器需有可旋转单张投射图。
- 废弃：3.8 节"不对口 4 条规则"中按武器借动作的说法，以本节为准。

### 12.4 v1.0 澄清（11-19 20:21，答游戏开发部）
- 基础动作 8 个（去掉胜利）+ 1 个通用施法（cast，全职业共用，阵法师用插旗）+ 18 个职业攻击 = 27 个。
- 阵法师只有 1 套攻击动作（插旗/挑刺）；拿非枪武器时动作不变，只把落下物换成该武器的单张图（「学艺不精」）。
- 收集角色：同职业、同性别的角色共用身体与服装，靠不同的头部/发型/配色区分；每个角色性别固定。
- 男女不共用体型：按 v8 定稿，男女各一套身体底板（骨骼与锚点规范一致）；服装款式设计男女共用，按各自版型分别出图。白/绿/蓝三档同一套图换色，紫/橙/红/暗金独立出图 → 每职业每性别 5 套独立出图（白底 1 + 紫橙红暗金 4）+ 2 套换色（绿、蓝），全量 6×2×5=60 套独立出图 + 24 套换色 = 84 套外观。第一版需 3 个头（主角 + 2 同伴）。
- 强化贴纸：第一版切片只做第 1 档（总和 >60），程序按 4 档配置预留。
