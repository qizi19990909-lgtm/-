# 修仙小队 · 技术样品（Godot 源代码）

子七工作室 · 游戏开发部。这是试效果用的简单样品，美术全部是占位图，不是正式版本。

## 在任意电脑上运行

1. 安装 **Godot 4.7.2 stable**（标准版，不是 .NET 版）：从 [Godot 官网](https://godotengine.org/download/archive/) 下载对应系统的版本，解压即可用，不用安装。
2. 下载本仓库：网页上点绿色「Code」→「Download ZIP」并解压；或者用命令 `git clone https://github.com/qizi19990909-lgtm/xiuxian-squad-sample.git`。
3. 打开 Godot →「导入」→ 选中仓库里的 `project.godot` →「导入并编辑」。第一次打开会自动导入资源，等几秒。
4. 按 **F5**（或右上角 ▶）运行。

## 怎么玩

- 3 名角色（战士、弓手、法师）自动打最近的怪，角色自身没有技能；技能全部来自装备词条，冷却好了自动放。
- 左键点角色是选中，再左键点地面让他走过去；右键取消选中；键盘 1/2/3 也能选人。
- 共 5 波 + 挑战波（`data/config.json` 的 `waves`）：第 1~4 波小怪+精英，第 5 波「山贼头目」（头目蓄力时脚下有红圈，把人拉出红圈可以躲开），之后是「挑战波：山贼精锐」。同屏最多 20 只怪（`max_on_screen`），多的分批刷。
- **装备系统可玩版**（v1.3，见下文「装备系统」）：打怪掉装备，按 B 或右上角「背包」打开背包（打开时战斗暂停）。7 档品质：白、绿、蓝、紫、橙、红、暗金。外观档 = 衣服和头盔中稀有度较低的一件（`config.json` 的 `look_tier_slots`），饰品、腰带等不参与；武器单独按武器品质换色发光。
  - **剑修（战士）**：1:1 头身（头顶到下巴 = 下巴到脚底，可用 `python3 tools/swordsman_measure.py assets/swordsman_tiers/*_body_*.png` 量）的 Q 版，七档身体高度统一，有正面和 3/4 侧面两个角度。战斗中（待机、移动、攻击）都用侧面图，朝右是原图、朝左镜像；待机也用侧面，是为了站住和走动之间不来回换角度、画面不闪。打开装备面板时转成正面，当换装预览。**注意：剑修现在的比例和弓手、法师（约 2.5 头身）不一样，这是试做版的已知差异。**
  - 七档是七套独立服装（白素衣 / 绿短打 / 蓝衣肩甲 / 紫袍头冠 / 橙金袍金冠 / 红衣头带 / 黑金甲披风金冠），再按档加特效：蓝 水雾、紫 紫雾、橙 金光和闪光点、红 火焰、暗金 背后光环 + 光柱 + 4 把环绕飞剑 + 披风摆动。待机呼吸、移动颠步、攻击挥剑带刀光、受击闪红后仰、倒地都是代码做的动作。换装面板里一点就立刻生效。
  - 弓手、法师：暂时还是整件衣服换色（试做版只做了剑修）。

## 装备系统（feat/equipment-v1.3）

- **数据**：`data/equipment.json` 是装备系统 v1.3 数值表（整数属性、13 部位、7 品质、独立爆率、强化/吞噬/宝石、体修套装、新伤害公式与仇恨参数）。角色逐级基础、怪物数值、强化成功率、爆率、技能词条都从这里读。
- **开局装备（总经理决定，方案 C）**：`config.json` 的 `starter_gear_override` 覆盖数值表的 `starter_gear`——3 人各送 13 部位 10 级白装 +0，角色 10 级。删掉这个键即恢复表里的 `starter_gear`。
- **输了重打（总经理方案 A）**：输了背包和已穿戴装备都保留（随存档 `user://save_equip_v13.json` 保存；旧存档不读取）；「已解锁最高波次」`max_wave` 也存进同一个存档（打到过哪一波就解锁到哪一波，含头目波和挑战波）。失败界面有「从第 N 波重打」和「选波次」（1~N 任选），开局界面在已解锁到第 2 波以上时出现，同样可以选。重打会重新载入场景，英雄满血。数值、头目都没改。
- 重打模拟：`python3 tools/sim_retry.py 50`（新手开局，输了从最高波次重打 / 对照从第 1 波重打，自动换更好掉落，最多 30 局），结果在 `tools/sim_retry_result.txt`。
- 失败界面：主按钮「从第 1 波重打」，提示「装备不够？回前几波刷装备」；「从第 N 波重打」和选波次是次要选项（总经理定 a）。无尽失败时主按钮为「再战无尽」。都可用「返回选择模式」回到开局选模式。开局先点「开始游戏」，再选闯关或无尽。
- 仅模拟的掉率实验：`SIM_EXTRA="--sim-drop-boost=3" SIM_OUT=sim_retry_boost3_result.txt python3 tools/sim_retry.py 50 retry_campaign_w1`（前 3 波蓝/紫掉落占比 ×2，不改任何配置，游戏里不生效）。
- **仍是占位**：出售价（`config.bag.sell_price`）、属性显示名（`element_names`）、职业→武器类型（`hero_weapon_type`）。
- `data/equipment_rules.json`：v0.4 之后只剩表里没有的占位/工程设置：强化方案开关、区域、属性显示名、职业→武器类型、自动拾取秒数、模拟预设。加载时表里有的同名键一律以表为准（来源见 `tools/drop_test_result.txt` 的「参数来源」）。
- **强化方案**：`equipment_rules.json` 的 `"enhance_profile"` 一个键切换，默认 `"slice"`（单件 +10、门槛 21/61/75/91、成功率读 `profiles.slice.success_rates`：+5 起 95%→75%）；`"formal"` 为正式版（+30）。失败按 `enhance.fail_drop`/`safe_floor`（试玩版 +0~+10 全是 0，失败不掉级），每次失败 +`blessing_per_fail`（5%）祝福、成功清零；按钮上显示绑银/炼器石消耗（样品没有货币，不扣）。
- **玩法**：
  - 怪物死亡按普通/精英/Boss 独立掉装备（每只怪单独掷点，没有保底；每个阶段白到暗金都可能出，30 级以下爆率约翻倍）。地上有品质色宝箱和名字；点一下拾取，2.5 秒后自动拾取。也会掉宝石。
  - 背包：点装备弹出短详情卡（名字和边框用品质色，不写品质文字）。格式为「名字 +强化」、等级、部位或武器类型、主属性，再缩进列出词条、技能和套装属性；孔位用圆圈表示。卡片高度随内容增高且无滚动条，超出屏幕高度时向右分列继续显示。同部位已有装备则左右对比，并在数值后用绿色 ▲+ 或红色 ▼- 标出差值。套装和有条件的词条：达到条件高亮，未达到变灰，不写「需要 X 件」。点「穿戴」或点卡片外关闭。界面字号较此前大约放大 30%。开局背包有 3 把按正常 10 级暗金规则生成的测试武器（剑/大刀/法杖）。只有法杖「玄元杖」保证带法修技能「澄源术」（为生命比例最低的队友回复生命上限 12%，冷却 8 秒）；剑和大刀按正常规则出非治疗技能，不强制澄源术。噬魄只会出现在暗金武器上，开局三把是否带噬魄也按暗金词条池投，不强制。暗金品质色为暗红金 `#C6561E`。掉落不再随机出定时回血。开局先点「开始游戏」，再选闯关模式或无尽模式，两种模式共用存档和装备。
  - 3 名角色 × 13 个部位都能穿/卸。**老板决定 2026-11-20：任何职业都可以装备任何装备**（`config.json` 的 `equip_class_restriction: false`）；武器类型（剑/大刀/锤/枪/法杖/弓）只决定名字，武器只提供属性，角色的攻击方式、技能和手里的武器贴图仍按职业。掉落的武器类型从数值表全部类型里随机。
  - 挑战波只有真正击杀头目后才解锁（存档 `boss_killed`），「再来一波」也只在击杀头目后出现；旧存档/调试存档里没杀头目却解锁了挑战波的，读档时压回第 5 波。干净存档端到端测试：删掉 `user://save_equip_v13.json` 后 `godot --path . -- --test-clean-defeat`。
  - 孔数按稀有度（白绿 0、蓝紫 1、橙红 2、暗金 3），点空孔选宝石镶嵌，点已镶的拆下；「宝石」页同名同级 3 颗合成 1 颗高一级。被吞噬的装备上的宝石直接消失，强化等级不继承。
  - 强化按钮显示成功率；30 级以下单件最高 +10，30 级起最高 +20。同一等级各品质每次加的整数相同。左下显示全身强化总和和点亮了第几档全身特效。
  - 伤害为整数：`max(四舍五入(攻击×0.45), 攻击−防御, 1)`，再结算会心和属性。防御只会削弱伤害，不会打出 0。仇恨记在怪物身上：刚刷出或还没有仇恨时打最近的角色，之后按仇恨表（战士伤害×2.5、承伤×1.5，法修 1.0/0.3，弓手 1.0/0.4）；新目标仇恨需超过当前目标的 110% 才切换。嘲讽是一次性仇恨加成 + 2 秒强制目标，不能永久锁定，结束后回到仇恨表。
  - 打完挑战波（或打过头目后挑战波失败）可以点「再来一波（刷怪）」继续刷；右下「试玩统计」显示击杀数和各品质掉落数（真实爆率，无改爆率作弊开关），可清空存档重来。
  - 背包 120 格（`config.json` 的 `bag.capacity`），满了地上的装备不再拾取并提示；「一键出售白绿」卖掉背包里白/绿装（已穿戴和点了「上锁」的不卖），所得显示为绑银。卖价 `bag.sell_price` 是占位（表里没有出售价）。
  - 背包、穿戴、宝石、试玩统计存到 `user://save_equip_v13.json`，下次打开继续。
- **测试**：
  - `godot --headless --path . --script tools/test_v13.gd`：抽检 v1.3 整数强化、掉落和伤害公式。
  - `godot --headless --path . -s res://tools/drop_test.gd`：每种怪 1000 次击杀看掉率 + 1000 次必掉看稀有度分布，对照区域表，检查不出紫以上、词条/孔/品相、Boss 保底、强化方案切换和字段缺失兜底。结果写到 `tools/drop_test_result.txt`。
  - `python3 tools/sim_difficulty.py 50`：难度模拟，预设（`sim_presets`）：全白 +0 / 平均 +5（绿蓝混装）/ 蓝紫 +5 / 全紫 +10（均 10 级、10 个部位）/ starter（新手流程：开局实际装备，不换装）/ starter_autoequip（新手流程：每波开始自动换上更好的掉落），各跑 50 场完整 5 波 + 挑战波，统计每波通过率与用时、总用时、存活人数，结果写到 `tools/sim_difficulty_result.txt`。
  - `godot --headless --path . -- --autotest`：自动用全紫 +10 打完 5 波 + 挑战波 + 1 轮刷怪，期间调试掉落、自动穿装备、镶宝石、强化、背包满/一键出售；有显示器时（如 `xvfb-run`）截图到 `截图/equip_*_iphone.png`。

## 修改数值

装备与怪物数值改 `data/equipment.json`（建议由创意部出新版表后整份替换）；波次编排、挑战波怪物（`ch_*`，以表里怪物为底乘倍率）、怪物外形/射程/移速、职业技能、外观档规则、背包在 `data/config.json`。改完直接在 Godot 里按 F5 就能看到效果。

## 导出成 exe / 网页

Godot 菜单「项目」→「导出」，已经预设好 Windows 和 Web 两个导出配置。第一次导出需要按提示下载 4.7.2 的导出模板。

## 目录

- `project.godot`、`main.tscn`：工程入口
- `scripts/`：GDScript 代码
- `assets/`：占位美术和字体（Noto Sans SC 子集）
- `data/config.json`：职业技能、怪物外形、波次/挑战波、外观档规则、背包配置
- `data/equipment.json`：装备系统 v1.3 数值表；`data/equipment_rules.json`：剩余占位与模拟预设
- `scripts/equip_db.gd`：装备表加载、掉落、生成、属性和伤害公式；`scripts/inventory_ui.gd`：背包界面；`scripts/loot.gd`：地上掉落物
- `tools/`：开发工具（`extract_weapon_layers.py` 生成武器层图片；`equip_shot.tscn` 生成换装对比截图；`make_swordsman_tiers.py` 把剑修 AI 原图去底、拆剑层、对齐；`swordsman_tiers_shot.tscn` 生成剑修七档正面/侧面对比截图和暗金实战截图；`drop_test.gd` 掉落分布测试）
- `assets/swordsman_tiers/`：剑修七品阶贴图（正面 `front_*`、侧面 `side_*`；`raw/` 是 AI 原图留档、`_archive_v1/` 是弃用的第一版，都不导入游戏）
- `assets_license.csv`、`第三方许可/`：素材授权清单
- `截图/`：样品运行截图

## 分支规则

`main` 分支只放老板验收过的版本，后续开发都走独立分支和 PR。
