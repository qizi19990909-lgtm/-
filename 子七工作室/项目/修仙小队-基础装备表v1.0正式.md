## 一、换算规则

1. 固定值（攻击、生命、防御）已按 15 倍放大，全部四舍五入取整（0.5 进位）。
2. 攻速、移速、会心是百分比，不随等级做 15 倍放大，只随品阶小幅提高。
3. 同一档内，白色到暗金名称相同，只靠颜色和数值区分。
4. 本表列出白装和暗金两端。中间品阶按白装乘倍率取整：

| 品质 | 倍率 |
| --- | --- |
| 白 | 1.00 |
| 绿 | 1.06 |
| 蓝 | 1.12 |
| 紫 | 1.18 |
| 橙 | 1.24 |
| 红 | 1.30 |
| 暗金 | 1.38 |

公式：某品质数值 = 四舍五入(该档白装数值 × 该品质倍率)。例如 10 级武器攻击：白 480，绿 509，蓝 538，紫 566，橙 595，红 624，暗金 662。

档位重叠仍成立：30 级红武器攻击 4680，40 级橙 4650，基本对齐；40 级暗金 5175，50 级橙 5189，基本对齐。

## 二、已确认、接入时一并遵守的规则

这些不是本表的数值格子，但是和基础表一起定下来的，后续做词条、技能、套装、怪物时按此执行。

**生命汲取**（原吸血，按自身生命上限回复，不按伤害计算）：

- 每次攻击回复自身生命上限的 0.5%～1.5%，1.5% 为 MAX。
- 多件合计最多 5%。
- 每秒通过生命汲取获得的生命，不超过生命上限的 10%。
- 群攻同时命中多个目标，只计算一次回复。

**50 级一身暗金（基础生命约 10.6 万）的挨打目标**，用于以后反推怪物攻击：

- 同级小怪：普攻掉 1%～2%，会心掉 2%～3%。
- 精英：普攻掉 3%～5%，会心掉 6%～8%。
- 首领：普攻掉 6%～10%，会心掉 12%～15%；大招掉 25%～35%，带读条。

**两种流派都要成立**：攻速汲取流打同级首领约 90～110 刀，爆发流约 60～70 刀。两种都需要一身暗金才能成型。
