# 修仙小队 词条池 v1.2 草案

- 日期：2026-11-22（Asia/Shanghai）
- 状态：草案，待老板确认
- 依据：基础装备表 v1.0、词条池 v1.1 草案，以及老板 t73u、t74u 反馈
- 说明：纯文字设计，不改游戏代码、不碰 GitHub。在 v1.1 基础上取消汲取上限，改为按命中目标结算，并补上橙/红/暗金群战分层。文中数字是建议值，待做怪物表时确定。

## 1. 相对 v1.1 的主要改动

老板指出：后期地图怪物密集，首领伤害高，还有火爆炸、冰冻冰缓、首领眩晕等。战士嘲讽 20 只怪加首领时，如果限制攻速和吸血频率，会拍两下就死。只要把汲取做成自身最大生命的百分比，再配好数值，围殴时才能回得过来。同时：只有橙装、红装的玩家也要有机会过图；橙装加套装能打，但容错低；暗金要明显轻松，让装备提升有意义。

本版因此做了这些修改：

1. **取消生命汲取的全身每击 5% 上限和每秒 10% 上限**，也不再限制汲取频率。攻速本来就不设上限，这里再确认一次。
2. **汲取始终按自身最大生命百分比回复。** 每次攻击每命中一个目标结算一次，范围攻击打 20 只就回 20 次。词条、技能、套装的百分比加算。
3. 装备词条汲取**仍只在暗金第 5 栏**出现（武器、衣服、戒指、项链）。橙、红没有第 5 栏，过图续航主要靠**套装汲取**。
4. 套装汲取建议值：**2 件 0.35%，4 件 0.70%**。锚点是 50 级橙装+4 件套，在 20 只小怪+首领且打满 21 个目标时勉强站住。
5. **分层要拉开：** 橙装+套装能过图但容错低；红装+同一套装更稳，仍不如暗金；暗金靠第 5 栏词条汲取明显轻松。
6. 平衡全部放在怪物侧：读条大招、短时降治疗或禁疗、控制、必须躲开的范围。不砍装备。

词条条目数量与 v1.1 相同，仍为 **72** 条（普通 25，高级 29，稀有 18；其中基础增益 58，固定增益技能 14）。变化在规则、结算和验算，不改词条种类。

v1.1 相对 v1.0 的改动仍然有效：去掉装备侧全身上限和联合约束，五种属性，会心不设上限，增伤单独计算再合计，debuff 取最高，取消主动/被动之分。


## 2. 设计原则

1. 人物和装备数值先确定，允许重复堆主修（例如一件暗金 4 条雷属性伤害 + 1 条汲取）。
2. 不为防刷太快而削弱词条。打得快还是慢，用怪物的抗性、会心抵抗、减伤和生命来调。
3. 堆属性必须比无属性明显更强；打上任何属性石，都要比同一件无属性装备收益更高。
4. 词条池以基础数值和固定增益为主；叠层状态、限时自身增益、给怪物上 debuff，放到技能池。
5. 所有技能自动生效，不需要手动点击。
6. 汲取不设全身上限和每秒上限，按目标结算；橙装靠套装过图但容错低，暗金要明显更轻松。

## 3. 五种属性与属性石

| 属性 | 方向（词条只给伤害和抗性，状态类放到技能池） |
| --- | --- |
| 火 | 偏灼烧和持续压力 |
| 冰 | 偏减速、降低命中 |
| 雷 | 偏易伤和爆发手感 |
| 毒 | 偏叠层持续伤害 |
| 暗 | 偏残血增伤，与汲取协同 |

属性石是未来系统，本草案先把计算公式和「任意属性石高于无属性」这条原则定下来。建议属性石做三件事：

1. **附着**：让本次攻击带上该属性。没附着时，属性增伤词条不生效。
2. **属性石增伤 S%**：与词条里的该属性增伤加算，再被怪物该抗性抵消。建议：绿 8%、蓝 10%、紫 12%、橙 15%、红 18%、暗金 20%。
3. **附着保底 P%**：不受抗性影响。建议先统一 10%（若希望随品质变化，可按绿 6% 到暗金 12%）。

这样，即使怪物抗性 100%、词条属性增伤全部被抵消，打上石头后仍比无属性高出 P%。打同一只抗性 0 的怪，只打石头、还没有属性词条时，收益为 P+S，暗金石就是 30%。

同一击只结算一种附着属性，火和雷不会互乘。

## 4. 伤害公式

### 4.1 基础伤害（与基础数值表同一套）

- 攻击 = 裸攻击 × (1 + 攻击百分比合计)。**攻击百分比只加攻击力，不加最终伤害。**
- 有效防御 = max(0, 防御 × (1 − 怪物固有穿透 − 自身无视防御合计) × (1 − 减防 debuff))。精英固有穿透 20%，首领 40%。减防 debuff 取最高的一条，不叠加。
- 当有效防御 / 攻击 > 1.5 时，按既定规则可能闪避，伤害为 0。
- 基础伤害 **H0** = 四舍五入( 攻² / (攻 + 有效防御) )。

### 4.2 会心（不设堆叠上限）

- 有效会心率 **p** = max(0, 会心率 − 怪物会心抵抗)。
- 例子：会心率 100%、怪物抵抗 50%，有效 50%；会心率 120%、抵抗 80%，有效 40%。
- 会心率可以堆过 100%，用来抵消抵抗。抵消后若仍 ≥ 100%，本次必会心。单次攻击最多会心一次，多出来的部分不额外加伤害。这不是给人物会心率设上限。
- 有效会心伤害 **c** = max(120%, 会心伤害 − 怪物会心防御)。120% 是建议下限，避免会心比普通击还低。
- 含会心基础 **Hc** = H0 × (1 − p + p × c)。下面举例里的 p、c 都按小数算。

### 4.3 每种增伤单独计算，再合计

先算出 Hc，再对每一个增伤项单独算增量，最后加起来：

- 增量_i = Hc × 有效增伤_i
- **最终伤害** = 四舍五入( (Hc + 全部增量之和) × (1 − 怪物减伤) )
- 也就是：最终伤害 = 四舍五入( Hc × (1 + 有效增伤之和) × (1 − 怪物减伤) )

各项是**加算后合计**，不是 (1+属性) × (1+对首领) × (1+通用) 连乘。

各分项这样取：

- **属性增伤**（已附着时）：P + max(0, 词条该属性增伤 + 属性石 S + 属性穿透 − 怪物该抗性)。怪物抗性可以为负，表示弱点。未附着时，这一项为 0，词条里的属性增伤也不生效。
- **对首领增伤**：只对首领生效。
- **对精英增伤**：只对精英生效。
- **通用增伤**（伤害加深）：对所有目标生效。
- 以后若有独立分项（例如暗属性的残血增伤），同样单独算增量，再进入合计。

**例子。** 含会心基础 Hc = 18165。已打暗金雷石（P=10%，S=20%），词条雷伤 72%，穿透 14%，怪物雷抗 20%，对首领 0，通用 0，怪物减伤 10%。

- 有效雷伤 = 10% + max(0, 72% + 20% + 14% − 20%) = 10% + 86% = 96%
- 增量_雷 = 18165 × 96% = 17438
- 最终 = 四舍五入( (18165 + 17438) × 0.90 ) = **32043**

如果同一击不对属性石、也没有其他增伤，最终 = 18165 × 0.90 = 16349。只打石头、不堆雷伤词条、雷抗 20% 时，有效属性 = 10% + max(0, 0+20+0−20) = 10%，最终 = 18165 × 1.10 × 0.90 = 17983，比无属性高出正好 10%。

### 4.4 debuff 取最高

给怪物上的减防、减命中、减速、降低抗性等，**同一类只取最高值，不叠加**。不同类可以同时存在（例如一条减防、一条减速）。

攻击者自己的「无视防御」是自身属性，可以和词条、固定增益技能加算，不是 debuff。

## 5. 投放规则

- 词条栏仍是：白 0、绿 1、蓝 2、紫 3、橙 4、红 4、暗金 5。权重仍是普通 70%、高级 25%、稀有 5%。
- **基础增益可以重复**，同一件暗金可以洗出 4 条雷属性伤害 + 1 条汲取。
- **生命汲取只在暗金第 5 词条出现**，建议仍只出在武器、衣服、戒指、项链。该栏汲取相对权重约 35%。技能池、套装池以后也会有汲取，与词条百分比加算，**不再设全身或每秒上限**。
- **固定增益技能**建议只在武器、衣服、裤子出现，**每件最多 1 条**。洗出第 2 条则只重抽这一条。它们是常驻固定加成，无需点击，无叠层、无概率、无持续时间。
- 橙以上仍可保留一条不可洗的技能槽，改为自动生效的技能池技能（叠层、自身状态、怪物 debuff），不再分主动、被动，不用点击。

## 10. 怪物侧平衡框架

人物和装备的数字先定死。节奏靠怪物的抗性、会心抵抗、会心防御、减伤、防御和生命来调。

### 10.1 设计方法

1. 先估该等级「专注主修」大概能堆到的单属性增伤中位数 **M**（含属性石 S，不含保底 P）。50 级建议 M 约 90–110%。例如 12 条平均 6% 的雷伤 + 暗金石 20%，约为 92%。
2. 普通怪各抗大约 0–0.15M；精英主抗大约 0.2M–0.3M，可以带一个弱点。
3. 均衡首领各抗大约 0.25M–0.35M，让主修明显优于无属性，但不会无脑秒掉。
4. 属性首领主抗大约 0.6M–0.8M，弱点 −10%～−25%。被克时主修优势缩小，改打弱点属性会重新领先——这就是堆属性的意义。
5. 会心抵抗、会心防御按会心流中位数来设：小怪低、精英中、首领高。特别耐会心的首领可以把会心抵抗放到 50–80%，用来对冲会心爆发，而不是给人物会心率加上限。
6. 首领生命按「典型暗金主修打均衡首领，每击约 1.2–1.8%」反推，并留区间。v2.4 的 170 万，是按还没计入属性石和属性增伤的爆发刀（约 25369）反推的。本版公式下同样的刀会更高，所以建议上调生命，或提高抗性和减伤来接住，**不要再回头限制装备**。

生命随等级可先跟着官方装备和人物攻击预算走（斜率可参考白武器攻击的平方关系），再按小怪 / 精英 / 首领乘系数。抗性和会心抵抗不必按等级直线拔高，按该级玩家能堆到的中位数重估即可。

## 11. 生命汲取结算（v1.2）

汲取始终按**自身当前最大生命的百分比**回复，不按造成的伤害计算。单条词条仍建议 0.5–1.5%（1.5% 显示 MAX）。这个区间先保持，用套装百分比和怪物反制来分层，不在这里砍装备词条。

结算规则：

1. 每次攻击每命中一个目标，按当前汲取合计百分比回复一次。
2. 一次范围攻击（横扫、火爆炸、冰霜范围等）命中 N 个目标，结算 N 次。嘲讽了 20 只就回 20 次。
3. 同一次攻击打在同一个目标上只结算一次。多段或爆炸默认不重复吃同一目标，除非效果明确写成多次独立命中。
4. 未命中、被闪避、伤害为 0 的攻击不结算汲取。
5. 灼烧、毒等持续伤害默认不结算汲取，除非该效果写明「可汲取」。
6. 词条、技能池、套装的汲取百分比**线性加算**。不设全身上限，不设每秒频率上限，攻速也不设上限。
7. 生命回满后，溢出的回复无效。
8. 被眩晕、击飞、冰冻而无法攻击时，攻击类汲取暂停；法修澄源术这类周期性治疗仍可生效。
9. 「治疗效果」加成法修、药水和套装治疗，**不加成**生命汲取，以免和汲取百分比叠乘。

装备词条汲取仍只在暗金第 5 栏、且仅武器、衣服、戒指、项链可出。

## 12. 橙装、红装的续航来源与套装建议

橙、红没有第 5 栏，出不了词条汲取。若只把续航放在随机技能槽上，抽到凝神而不是汲取就可能过不了图。所以**过图的稳定门槛是套装汲取**，技能池汲取和法修是增强。

| 来源 | 作用 | 建议 |
| --- | --- | --- |
| 套装汲取 | 过图的稳定门槛 | 2 件 0.35%，4 件 0.70%。按最大生命、每命中一个目标结算。橙/红/暗金用同一套数值，差异来自生命、攻速、减伤和第 5 栏词条 |
| 技能池汲取技能 | 增强，不是门槛 | 建议橙 0.8%、红 1.2%、暗金 1.5%。抽到会更稳；过图不绑在这颗技能上 |
| 攻速词条 | 提高每秒结算次数 | 不设上限。围殴时要把套装汲取打满，必须有足够攻速和范围攻击 |
| 眩晕抗性、韧性 | 减少汲取被打断的时间 | 被控时 20 只怪仍在打，这是橙装容错低的主要原因之一 |
| 法修澄源术、治疗套装 | 组队补充，尤其是被控期间 | 澄源术大约每秒 0.8–1.5% 生命，帮不了围殴主回血，但能在控制窗口补一口 |
| 范围攻击（横扫、火爆炸等） | 让每目标结算真正打满 20 只 | 打不满就回不过来 |

套装 0.70% 的锚点：50 级橙装、攻速约 50%，嘲讽 20 只小怪加首领，并用范围技能打满 21 个目标时，每秒回复只略高于每秒受伤。这就是「有机会打、容错低」。2 件套 0.35% 扛不住这场围殴，需要凑齐 4 件。

## 13. 群战验算与怪物反制

### 13.1 验算口径（建议值）

场景：50 级战士嘲讽 **20 只同级小怪 + 1 只同级首领**。

- 生命用官方 50 级全身基础生命（无词条百分比）：橙 97382，红 101280，暗金 106468。
- 受伤按暗金目标中位换成绝对伤害，橙红吃同样的绝对量，所以占自身生命的比例略高：小怪期望每击 1703（普通 1.5%、会心 2.5%，会心约 10%），每 2.0 秒打一次，20 只都打得到人；首领期望每击 9981（普通 8%、会心 13.5%，会心约 25%），每 2.5 秒一次。大招 30% 暗金生命，绝对值 31940，带读条。
- 未算减伤前，每秒受伤 21027。
- 基础每秒攻击 1 次，再乘 (1+攻速)。汲取按实际命中目标数结算。

- 橙装只有 2 件套（0.35%）、打满 21 个目标：每秒回复约 11.0%，低于 19.9% 的受伤，站不住。过图需要 4 件套。

结论：橙装+套装有机会过图，但必须聚怪、打满范围，并且不能连续吃控制或硬吃大招，容错低。红装同一套装更稳一层。暗金多了第 5 栏词条汲取，提升非常明显。装备对角色的意义拉得开。

### 13.2 怪物侧反制（不砍装备）

暗金群战会回得很快。不要重新加上每秒上限或全身上限，那会让橙装先撑不住。压力改由怪物技能和机制来给：

1. **读条大招**：单次 25–35% 最大生命（按暗金生命换成绝对伤害），带明确读条。没躲开会掉一大截，汲取回不满这一下，必须看读条走位。
2. **短时降低治疗或禁疗**：例如 5–8 秒内汲取和治疗降低 60–80%，或短时间完全禁疗。窗口里要靠减伤、走位或控制抗性硬抗，不能站着回。
3. **控制打断攻击**：眩晕、击飞、冰冻会让攻击类汲取暂停，20 只小怪仍在打。攻速续航流必须堆眩晕抗性和韧性。首领控制要配读条或可解，避免毫无反制地被控死。
4. **必须躲开的范围**：地面警告圈、全场爆炸、点名分散。怪被嘲讽堆在一起后，首领可以用范围压堆怪，逼玩家短暂拉开。
5. **不可被汲取的伤害（可选）**：少量阶段伤害或处决线不吃汲取，用来做机制惩罚，不要变成常规平砍，否则橙装更难过图。
6. **精英配合**：部分精英带禁疗或强控；密集小怪伤害高，但能被冰缓、冰冻、火爆炸处理。让攻速、汲取、控制抗性都有用。

## 14. 风险

1. 取消上限并按目标结算后，暗金在群战中的回复会远高于受伤。如果不做读条大招、禁疗和控制，就会无限站撸。必须在怪物表里把这些反制做出来，而不是回头给汲取加上限。
2. 橙装+套装高度依赖「打满被嘲讽的怪」。范围技能半径、怪物碰撞和嘲讽范围会直接影响能不能过图，技能和关卡要按这个验算口径对齐。
3. 50 级受伤数字沿用暗金受伤目标中位，小怪和首领的攻击间隔是建议值（2.0 秒 / 2.5 秒）。间隔一变，套装百分比就要重估。
4. 套装、技能池尚未正式设计，这里只锁定「按最大生命百分比、每目标结算」和 2/4 件建议值。
5. v1.1 里已经指出的风险仍然在：属性石公式、首领生命口径、强化 +20 的算法，做怪物表时要一并统一。数字都是建议值，等试玩后再调。
